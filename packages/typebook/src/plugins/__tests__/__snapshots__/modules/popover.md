## popover

A panel floating next to an element.

```tsx
import { Popover, PopoverTrigger, PopoverContent } from "@acme/ui/popover";
```

### Popover

The popover state root.

| Prop | Type | Default | Required | Description |
|---|---|---|---|---|
| `children` | `ReactNode` | – | – | – |

### PopoverTrigger

Opens the popover.

| Prop | Type | Default | Required | Description |
|---|---|---|---|---|
| `children` | `ReactNode` | – | – | – |

### PopoverContent

The floating panel.

> ⚠️ **Deprecated:** Use `Popover` children.

| Prop | Type | Default | Required | Description |
|---|---|---|---|---|
| `children` | `ReactNode` | – | – | – |
